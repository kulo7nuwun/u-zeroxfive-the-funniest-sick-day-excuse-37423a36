A [make.fun](https://make.fun/c/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) entry for **The Funniest Sick-Day Excuse**: one line, under 200 characters, that someone could send to call in sick — the funniest excuse in one breath.

## The line

> Can't come in — I locked myself in my own bathroom, the handle came off in my hand, and the locksmith is stuck in traffic behind my plumber.

140 characters. Half believable, fresh, and the laugh lands on the last three words.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (one line, UTF-8, 1–200 characters).
